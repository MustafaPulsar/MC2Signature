How to add it to Outlook

Classic Outlook for Windows

  1. Fill in your details above and click Copy signature.
  2. Open Outlook and go to File > Options > Mail, then click Signatures...
  3. On the E-mail Signature tab, click New, type a name (for example MC2) and click OK.
  4. Click inside the Edit signature box and press Ctrl + V to paste.
  5. Click Save.
  6. On the right, under Choose default signature, set New messages and Replies/forwards to your new signature.
  7. Click OK, then OK again to close Options.
  8. Send a test email to check the banner and logo appear.
Alternative: use the downloaded .htm file
  1. Click Download .htm file above.
  2. Close Outlook.
  3. Press Windows + R, type %APPDATA%\Microsoft\Signatures and press Enter.
  4. Move the downloaded .htm file into that folder.
  5. Open Outlook, go to File > Options > Mail > Signatures... and set it as your default.

New Outlook for Windows

Copying from Word puts the images inside the signature, so it doesn't rely on this website staying online. The same Word file also works for Classic Outlook.

  1. Fill in your details above and click Download Word file (Windows).
  2. Open the downloaded .docx file in Microsoft Word. If a yellow Protected View bar appears, click Enable Editing.
  3. Press Ctrl + A to select everything, then Ctrl + C to copy.
  4. In Outlook, click the Settings cog (top right), then Accounts > Signatures.
  5. Click New signature, give it a name (for example MC2), click in the signature box and press Ctrl + V to paste.
  6. Under Select default signatures, choose it for New messages and Replies/forwards, then click Save.
  7. Send a test email to yourself to check the banner and logo appear.

If the banner or logo pastes as an empty box, delete it and add the picture with the picture button in the signature editor instead.

Outlook for Mac

Copying from Word puts the images inside the signature, so recipients see them straight away instead of a "Download pictures" message.

  1. Fill in your details above and click Download Word file (Mac).
  2. Open the downloaded .docx file in Microsoft Word. The banner and logo look bigger than the black block in Word - that's on purpose, they come out the right size in Outlook.
  3. Press Cmd + A to select everything, then Cmd + C to copy.
  4. In Outlook, go to Outlook > Settings > Signatures and click + to add a new signature.
  5. Give it a name (for example MC2), click in the signature box and press Cmd + V to paste.
  6. Save it, then set it as the default for New messages and Replies/forwards.
  7. Send a test email to yourself and check it there - the signature box in Outlook's settings doesn't always show the true sizes.

If the signature looks white instead of black, Outlook is in dark mode - switch to light mode (Outlook > Settings > General > Appearance) to check it. Recipients see the original colours.
